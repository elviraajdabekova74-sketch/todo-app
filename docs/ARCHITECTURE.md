# Архитектура: Список дел (To-Do List)
## Компоненты
- main.py — точка входа, запускает меню
- ui.py — меню, ввод данных и вывод списка дел
- logic.py — добавление, отметка выполнения и удаление дел
- storage.py — сохранение списка дел в файл tasks.txt
## Связи
main.py запускает ui.py.
ui.py обращается к logic.py.
logic.py читает и сохраняет данные через storage.py.
Обратные вызовы запрещены: storage не знает о ui и logic.
