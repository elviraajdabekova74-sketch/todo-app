## Классы
- Task: одно дело, хранит название, срок и статус.
- TaskManager: хранит список дел, добавляет, удаляет и ищет.
- ConsoleUI: меню и вывод на экран.
- Storage: базовый класс хранилища, описывает методы load и save.
- FileStorage: хранит дела в файле.
- MemoryStorage: хранит дела в оперативной памяти.

## Связи
- ConsoleUI → TaskManager: ассоциация, интерфейс знает о менеджере.
- TaskManager o-- Task: агрегация, менеджер содержит список дел.
- TaskManager ..> Storage: зависимость, менеджер использует хранилище при сохранении.
- FileStorage и MemoryStorage наследуют Storage, так что способ хранения можно сменить.
- Storage и его наследники не связаны с ConsoleUI: зависимость идёт только вниз.
