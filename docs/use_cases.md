## Прецедент «Добавить дело»
- Цель: зафиксировать новое дело в списке.
- Основной сценарий: пользователь выбирает пункт меню 1, вводит название и срок.
- Альтернативный сценарий: название пустое, программа выводит сообщение об ошибке и повторяет ввод.

## Прецедент «Просмотреть список дел»
- Цель: увидеть все дела и их статус.
- Основной сценарий: пользователь выбирает пункт меню 2, программа выводит список.
- Альтернативный сценарий: список пуст, программа выводит сообщение «Дел пока нет».

## Прецедент «Отметить дело выполненным»
- Цель: показать, что дело сделано.
- Основной сценарий: пользователь выбирает дело из списка, программа ставит отметку «выполнено».
- Альтернативный сценарий: такого дела нет, программа сообщает об ошибке и возвращает в меню.

## Прецедент «Удалить дело»
- Цель: убрать ненужное дело из списка.
- Основной сценарий: пользователь вводит название дела, программа удаляет его.
- Альтернативный сценарий: дело не найдено, программа выводит сообщение и ничего не удаляет.

## Прецедент «Сохранить данные»
- Цель: не потерять список после выхода из программы.
- Основной сценарий: после каждого изменения программа записывает список в файл.
- Альтернативный сценарий: файл недоступен для записи, программа сообщает об ошибке.

## Прецедент «Напомнить о просроченных делах»
- Цель: не дать пользователю забыть о делах с истёкшим сроком.
- Основной сценарий: таймер проверяет сроки дел и выводит напоминание о просроченных.
- Альтернативный сценарий: просроченных дел нет, напоминание не выводится.
